# AWS Machine Learning Services 
---

## Amazon Rekognition

Phân tích **ảnh và video** bằng ML để nhận diện vật thể, con người, văn bản, cảnh vật.

- **Facial Analysis**: giới tính, độ tuổi, cảm xúc
- **Face Search & Verification**: so sánh khuôn mặt với database hoặc celebrity
- **Content Moderation**: lọc nội dung không phù hợp tự động
- **Text Detection**: đọc text trong ảnh (biển hiệu, biển số xe...)

---

## Amazon Transcribe

**Speech → Text** dùng ASR (Automatic Speech Recognition).

- Hỗ trợ transcribe cuộc gọi, tạo phụ đề (subtitles/captions), đánh index file media để tìm kiếm
- Có thể **redact** (ẩn) thông tin nhạy cảm tự động (PII)

---

## Amazon Polly

**Text → Lifelike Speech** dùng deep learning.

- Tạo ứng dụng "biết nói" (talking apps), đọc bài viết, hỗ trợ người khiếm thị
- Ngược chiều với Transcribe

---

## Amazon Translate

Dịch ngôn ngữ tự nhiên, chính xác, có thể xử lý **khối lượng lớn** văn bản.

- Dùng để **localize** nội dung cho người dùng quốc tế

---

## Amazon Lex

Xây dựng **chatbot / call center bot** – cùng công nghệ với Alexa.

- ASR: chuyển giọng nói → text
- NLU (Natural Language Understanding): hiểu **ý định (intent)** của người dùng
- Thường kết hợp với **Amazon Connect**

---

## Amazon Connect

**Cloud contact center** (tổng đài ảo trên cloud).

- Nhận cuộc gọi, tạo contact flow, tích hợp CRM
- Không cần trả trước, rẻ hơn ~80% so với tổng đài truyền thống
- Hay đi kèm Lex trong đề thi: _"tự động hóa tổng đài"_ → **Lex + Connect**

---

## Amazon Comprehend

**NLP** (Natural Language Processing) – serverless, fully managed.

- Phát hiện: ngôn ngữ, key phrases, entities (người, địa điểm, thương hiệu), sentiment (tích cực/tiêu cực)
- Phân loại tài liệu theo **topic**
- Use case: phân tích phản hồi khách hàng, gom nhóm bài báo

---

## Amazon SageMaker

**Nền tảng toàn diện** để build, train, deploy ML models – dành cho developer & data scientist.

- Giải quyết bài toán: khó tập hợp toàn bộ quy trình ML vào một nơi + tự provision server
- Exam tip: đề hỏi "ai đó muốn tự xây ML model" → **SageMaker**

---

## Amazon Forecast

Dự báo tương lai bằng ML, **chính xác hơn 50%** so với phân tích thủ công.

- Giảm thời gian từ vài tháng → vài giờ
- Use cases: dự báo nhu cầu sản phẩm, tài chính, tài nguyên

---

## Amazon Kendra

**Document search engine** powered by ML – tìm kiếm ngôn ngữ tự nhiên.

- Hỗ trợ: PDF, HTML, Word, PowerPoint, FAQs...
- Học từ hành vi người dùng để cải thiện kết quả
- Exam tip: "tìm kiếm tài liệu nội bộ bằng ngôn ngữ tự nhiên" → **Kendra**

---

## Amazon Personalize

**Recommendation system** real-time, fully managed.

- Cùng công nghệ gợi ý sản phẩm của Amazon.com
- Tích hợp được vào website, app, SMS, email
- Triển khai trong **vài ngày** thay vì vài tháng

---

## Amazon Textract

**OCR nâng cao** – trích xuất text, chữ viết tay, dữ liệu từ tài liệu scan.

- Không chỉ đọc text mà còn hiểu **cấu trúc** (bảng biểu, form fields)
- Use cases: hóa đơn tài chính, hồ sơ y tế, giấy tờ thuế/hộ chiếu

---

## Bảng tóm tắt nhanh (Exam Cheat Sheet)

|Service|Ghi nhớ nhanh|
|---|---|
|Rekognition|Nhận diện ảnh/video, khuôn mặt|
|Transcribe|Giọng nói → Text|
|Polly|Text → Giọng nói|
|Translate|Dịch ngôn ngữ|
|Lex|Chatbot (như Alexa)|
|Connect|Tổng đài cloud|
|Comprehend|NLP – phân tích văn bản|
|SageMaker|Tự build ML model|
|Forecast|Dự báo tương lai|
|Kendra|Tìm kiếm tài liệu thông minh|
|Personalize|Gợi ý cá nhân hóa real-time|
|Textract|OCR – đọc tài liệu scan|

> **Mẹo thi:** Lex + Connect thường xuất hiện cùng nhau trong scenario tổng đài tự động. Phân biệt Transcribe (speech→text tổng quát) vs Lex (speech→text + hiểu intent để build bot).
