# AWS Certified Cloud Practitioner (CLF-C02)

Chào mừng bạn đến với chuỗi tài liệu tự học và ôn thi chứng chỉ **AWS Certified Cloud Practitioner (CLF-C02)**. Mục này tổng hợp toàn bộ kiến thức cốt lõi từ cơ bản đến nâng cao về điện toán đám mây AWS.

## 📌 Mục tiêu khóa học
* Hiểu rõ khái niệm Điện toán đám mây và mô hình triển khai.
* Nắm vững các dịch vụ cốt lõi của AWS (Compute, Storage, Database, Networking).
* Hiểu về mô hình bảo mật chia sẻ (Shared Responsibility Model) và bảo mật trên AWS.
* Biết cách quản lý chi phí, billing và các gói hỗ trợ (Support Plans).
