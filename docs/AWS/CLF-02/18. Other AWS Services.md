# AWS – Các Dịch Vụ Khác 

---

## 🖥️ Desktop & Streaming

**Amazon WorkSpaces**

- Managed Desktop-as-a-Service (DaaS) – cung cấp desktop Windows/Linux trên cloud
- Thay thế hạ tầng VDI on-premise, scale nhanh đến hàng nghìn users
- Tích hợp KMS để mã hóa dữ liệu, tính phí theo tháng hoặc theo giờ

**Amazon AppStream 2.0**

- Stream ứng dụng desktop trực tiếp qua web browser – không cần cài đặt
- Hoạt động trên mọi thiết bị có browser, cấu hình instance theo từng loại app (CPU/RAM/GPU)

> **Phân biệt:** WorkSpaces = full desktop VDI | AppStream 2.0 = chỉ stream 1 app qua browser

## 📱 Mobile & Web Development

**AWS Amplify**

- Bộ công cụ phát triển full-stack web/mobile app (giống Firebase của Google)
- Tích hợp sẵn: Authentication, Storage, API (REST/GraphQL), CI/CD, Analytics, AI/ML

**AWS AppSync**

- Sync dữ liệu real-time giữa mobile/web app qua **GraphQL**
- Hỗ trợ offline sync, tích hợp DynamoDB/Lambda, bảo mật chi tiết (fine-grained security)
- Amplify thường dùng AppSync ở backend

**AWS Device Farm**

- Test app trên **thiết bị thật** (mobile, tablet, browser) – không phải giả lập
- Chạy test song song trên nhiều thiết bị, cấu hình GPS/Wi-Fi/Bluetooth

## 🌐 IoT & Media

**AWS IoT Core**

- Kết nối thiết bị IoT lên AWS Cloud một cách serverless, bảo mật, có thể scale
- Giao tiếp được với thiết bị **kể cả khi thiết bị offline**
- Tích hợp Lambda, S3, SageMaker để xử lý dữ liệu từ thiết bị

**Amazon Elastic Transcoder**

- Chuyển đổi định dạng media file trong S3 sang định dạng phù hợp với từng thiết bị
- Tính phí theo **thời lượng** (duration-based), fully managed

## 💾 Backup & Disaster Recovery

**AWS Backup**

- Quản lý tập trung backup cho nhiều AWS service
- Hỗ trợ: PITR, lifecycle policy, cross-region backup, cross-account backup (qua Organizations)

**AWS Elastic Disaster Recovery (DRS)**

- Khôi phục server vật lý/ảo/cloud lên AWS nhanh chóng (replication liên tục ở block-level)
- Use case: bảo vệ database (Oracle, MySQL), app doanh nghiệp (SAP), chống ransomware

## 🚚 Migration

**AWS DataSync**

- Chuyển lượng lớn dữ liệu từ on-premise lên S3/EFS/FSx
- Lần đầu full load, sau đó **incremental**, lên lịch theo giờ/ngày/tuần

**AWS Application Discovery Service**

- Thu thập thông tin on-premise để lên kế hoạch migration
- 2 chế độ: **Agentless** (VM inventory, hiệu năng) | **Agent-based** (processes, network connections)

**AWS Application Migration Service (MGN)**

- Lift-and-shift lên AWS, thay thế SMS cũ
- Convert server vật lý/ảo/cloud để chạy native trên AWS, downtime tối thiểu

**AWS Migration Evaluator**

- Phân tích hạ tầng hiện tại, xây dựng **business case** có dữ liệu cho việc migrate lên AWS

**AWS Migration Hub**

- Dashboard trung tâm theo dõi toàn bộ quá trình migration
- Tích hợp với MGN và DMS, có template sẵn cho SAP, SQL Server

## ⚙️ Operations & Workflow

**AWS Step Functions**

- Xây dựng visual workflow để orchestrate Lambda functions và các service khác
- Hỗ trợ: sequence, parallel, conditions, timeout, error handling, human approval
- Use case: order fulfillment, data pipeline, bất kỳ workflow phức tạp nào

**AWS Fault Injection Simulator (FIS)**

- Chạy thí nghiệm **Chaos Engineering** trên AWS workload
- Tạo sự cố có kiểm soát (tăng CPU/memory đột ngột) để phát hiện bug và bottleneck ẩn
- Hỗ trợ EC2, ECS, EKS, RDS

## 🛰️ Đặc biệt

**AWS Ground Station**

- Kiểm soát vệ tinh, nhận dữ liệu vệ tinh trực tiếp vào VPC trong vài giây
- Use case: dự báo thời tiết, chụp ảnh bề mặt, phát sóng video

**Amazon Sumerian**

- Tạo ứng dụng VR/AR/3D không cần kỹ năng lập trình hay 3D chuyên sâu
- Có template sẵn, chạy qua browser hoặc hardware AR/VR

## 📣 Messaging & Marketing

**AWS Pinpoint**

- Dịch vụ marketing communications 2 chiều (gửi + nhận reply)
- Hỗ trợ: email, SMS, push notification, voice, in-app message
- Scale đến **hàng tỷ tin nhắn/ngày**, có segment & campaign

> **Phân biệt:** SNS/SES = quản lý từng message | **Pinpoint** = quản lý toàn bộ campaign (template, schedule, segment)
